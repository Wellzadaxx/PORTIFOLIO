# Agenda de Metas

Calendário mensal para organizar tarefas e metas pessoais, inspirado na visualização de calendário do Notion.

**Acesse:** https://wellzadaxx.github.io/PORTIFOLIO/agenda/

## Funcionalidades

- Visualização por mês (grade) e em lista (ideal para celular)
- Tarefas com ícone, horário, tipo (Main/Side), dificuldade (Fácil/Média/Difícil) e status de concluída
- Progresso numérico opcional (ex.: 13/30 páginas)
- Projetos e áreas da vida: Grana, Mente, Físico, Social, Criativo e Disciplina
- Arrastar e soltar para remarcar tarefas entre os dias
- Duplicar tarefa para o dia seguinte
- Filtros por tipo e por área, e resumo de conclusão do mês
- Tema claro e escuro automático, de acordo com o sistema

## Tecnologias

HTML, CSS e JavaScript puro, sem frameworks. Os dados ficam salvos no `localStorage` do navegador.
